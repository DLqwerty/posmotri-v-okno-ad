# Проектная работа «Посмотри в окно»

Интерактивный веб-сервис для просмотра видеороликов с видами из окон различных городов мира с возможностью поиска по городу и фильтрации по времени суток.

Ссылка на репозиторий: https://github.com/DLqwerty/posmotri-v-okno-ad

## Функциональность
- Загрузка и воспроизведение видеопотока из базы данных через REST API.
- Интерактивный список карточек видео с плавной подгрузкой («Показать ещё»).
- Поиск по названию города.
- Фильтрация по времени суток (Утро, День, Ночь) с кастомными чекбоксами.
- Отображение прелоадеров в процессе загрузки контента.
- Обработка ошибок при отсутствии результатов поиска.
- Полная доступность интерфейса с клавиатуры (фокусные состояния `:focus-visible`).

## Стек технологий
- HTML5: семантическая разметка, теги `<template>`, `<video>`.
- CSS3: Flexbox, Grid, кастомный скроллбар, кастомные элементы форм (`appearance: none;`, `:checked`, `:has(:focus-visible)`), ограничение строк (`line-clamp`), `object-fit`.
- Шрифты: Oswald, Fira Sans Condensed (подключены через `@font-face` в форматах WOFF2 и WOFF).
- JavaScript (ES6+): асинхронные запросы Fetch API, работа с DOM-деревом и шаблонами.

## Запуск проекта
Для локального запуска откройте файл `index.html` в любом современном браузере (Google Chrome, Firefox, Yandex Browser) или запустите локальный веб-сервер.
